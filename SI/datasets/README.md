Datasets
========
This folder contains 12 datasets for basic calculations on chemical elements, physics particles, planets, moons, etc. Most of them have been converted from .CSV files (in CSVs subfolder) by the csv2hpp utility.

References
----------
1. chemical_elements.h converted from chemical_elements.csv by csv2hpp which has been downloaded from https://www.kaggle.com/datasets/berkayalan/chemical-periodic-table-elements (Other license).
2. exoplanets.h converted from exoplanets.csv by csv2hpp which has been produced by the NASA Exoplanet Archive: http://exoplanetarchive.ipac.caltech.edu on Mon Jan 12 06:51:06 2026.
3. material_properties.h converted from material_properties.csv by csv2hpp which has been downloaded from https://web.mit.edu/course/3/3.11/www/modules/props.html (MIT license).
4. montly_sunspots.h converted from monthly_sunspots.csv by csv2hpp which has been downloaded from https://www.kaggle.com/datasets/robervalt/sunspots (CC0 Public Domain license).
5. planets.h converted from planets.csv by csv2hpp.
6. moons.h converted from moons.csv by csv2hpp which has been downloaded from https://github.com/devstronomy/nasa-data-scraper (MIT license). See also https://en.wikipedia.org/wiki/List_of_natural_satellites.
7. musical_notes.h converted from musical_notes.csv by csv2hpp which has been extracted from https://www.liutaiomottola.com/formulae/freqtab.htm.
8. csv2hpp utility is available for free at: https://github.com/fleschutz/csv2hpp (CC0-1.0 license)
